Quick Start Guide

현재 Wi-Fi에 연결하는 방법을 포함한 네트워크 설정은 아래 Getting Started 섹션에서 쉽게 확인하실 수 있습니다.

전원 켜기

먼저 배터리를 커넥터에 연결하고, 진동이 완전히 멈출 때까지 'Middle Switch'를 길게 눌러주세요.

대화 시작하기

  1. 1. "Hi, AGORA"라고 말하세요.
  2. 2. 눈이 활성화될 때까지 3~5초간 기다리세요. (빨간색 LED 깜박임이 멈춥니다.)
  3. 3. 이제 이렇게 한번 말해보세요:
    • • “Introuce me about Agora ConvoAl Device Kit”
    • • "Introduce AGORA company"
    • • "Who is Bill Gates?"
    • • "What's 15% off a $328 dress?"

Getting Started

1단계: 전원 켜기

  • 배터리 케이블을 커넥터에 꽂으세요.
  • 진동이 완전히 멈출 때까지 'Middle Switch'를 길게 누르세요.
  • 스위치에서 손을 떼면 빨간색 LED가 깜박이고, "네트워크 연결에 실패했습니다. 네트워크를 확인해 주세요."라는 음성 안내가 나옵니다.

2단계: 네트워크 설정 모드 진입

  • Left Switch를 3초 이상 길게 눌러주세요.
  • "Please use bluetooth for network provisioning" 라는 음성 안내가 나옵니다.

3단계: Agora ConvoAl 앱 설치하고 로그인하기

  1. 오른쪽의 QR 코드를 스캔해서 ConvoAI 앱을 다운로드하고 설치해주세요.
  2. ConvoAI 앱을 열어주세요.
  3. 'Call AI Engine'을 탭해서 로그인 화면으로 들어가세요.
  4. 안내가 나오면 필요한 권한을 허용하고 로그인을 완료해주세요.

4단계: 네트워크 설정

  1. 왼쪽 상단의 메뉴 버튼을 탭하세요.
  2. 'Conversational AI Devices' 아래의 '+'를 탭하세요.
  3. 새 기기를 추가하려면 오른쪽 상단의 '+'를 탭하세요.
  4. '다음'을 탭하세요...
  5. 앱에 대상 기기가 표시되면 기기 이름을 탭하세요.
  6. 사용 중인 WiFi 네트워크 이름을 확인하세요.
  7. WiFi 비밀번호를 입력하고 '다음'을 탭하세요.
  8. '기기 추가됨' 확인 메시지가 표시될 때까지 3-5초간 기다리세요.

5단계: 대화 시작하기

  • 호출어: "Hi, AGORA" (눈 모양 화면이 활성화되고 빨간색 LED 깜박임이 멈출 때까지 3-5초 기다리세요.)
  • 다음과 같은 명령어를 사용해 보세요:
    • "Introduce AGORA company"
    • "Who is Bill Gates"
    • "What's 15% off a $328 dress?"

6단계: 전원 끄기

  • 3분 동안 사용하지 않으면 자동으로 절전 모드로 전환됩니다. (음성 안내: "AI 에이전트 연결이 끊어졌습니다.")
  • 절전 모드: 빨간색 LED가 꺼지고 진동이 멈출 때까지 'Middle Switch'를 길게 누르세요.
  • 완전 종료: 배터리 커넥터를 분리하세요.

FAQ

전원 조작

  • 전원 켜기: Middle Switch를 3초 이상 길게 누르세요.
  • 전원 끄기: 전원이 켜진 상태에서 Middle Switch를 3초 이상 길게 누르세요.

네트워크 설정

  • 네트워크 설정 모드 진입: 전원이 켜진 상태에서 Left Switch를 3초 이상 길게 누르세요.
  • 기기가 네트워크 설정 대기 상태로 전환됩니다.

볼륨 조절

  • 볼륨 높이기: Left Switch를 한 번 클릭하세요.
  • 볼륨 낮추기: Right Switch를 한 번 클릭하세요.

역할 전환

  • 1: 앱(APP)을 통해 역할을 전환하세요.
  • 2: 기기 오른쪽에 있는 Reset Switch를 사용하세요.
  • 참고: 역할을 전환한 후 기기를 다시 호출해야 과정이 완료됩니다.

충전

  • Type-C 포트를 사용하여 충전하세요.
  • 참고: 배터리 없이 Type-C 케이블을 직접 연결하여 전원을 공급하고 사용할 수도 있습니다.

핫스팟 전용 설정

  • 네트워크 설정을 건너뛰려면 핫스팟을 미리 설정하세요:
  • 이름: AGORA_AI_KIT
  • 비밀번호: 1234567890

LED 상태 표시등

  • 빨간색과 녹색 교차 깜박임: 네트워크 설정 대기 중
  • 빨간색 깜박임: 네트워크 연결 대기 중
  • 녹색 깜박임: 네트워크 연결됨, AI 에이전트 연결 끊김, 호출 대기 중

Wakeup

  • 호출어: "Hi, AGORA"

Wakeup Timeout

  • AI 에이전트 연결 끊김: 3분
