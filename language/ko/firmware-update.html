펌웨어 굽기(Burn Code)

Armino + BKFIL로 펌웨어를 굽는 방법을 정리했습니다.

홈으로

빠른 체크리스트

  • 노트북을 USB 케이블로 Type C-Port 1 에 연결합니다.
  • CH340 시리얼 툴 보드 사용을 권장합니다(baud rate 1500000).
  • BKFIL 준비: Windows(BKFIL.exe) / macOS(BKFIL).
  • all-app.bin 준비(보안 프로젝트 최초 1회는 bootloader.bin 포함).

개요

Armino는 Windows/macOS에서 펌웨어 굽기를 지원합니다. 이 페이지는 필요한 파일과 절차를 한눈에 이해할 수 있도록 요약했습니다.

빌드 산출물(.bin)

앱 프로젝트를 빌드하면 build/app/bk7258/ 아래에 all-app.bin 이 생성됩니다. 이 파일을 굽기(burn)할 수 있습니다.

보안 프로젝트를 처음 굽는 경우

먼저 bootloader.bin 을 굽고, 그 다음 all-app.bin 을 굽습니다.

시리얼(UART)로 굽기

참고

  • Armino는 Type C-Port 1 을 통한 굽기를 지원합니다.
  • 다운로드용으로 CH340 시리얼 툴 보드 사용을 권장합니다.
  • Windows에서는 현재 UART 굽기를 지원합니다.

절차

  1. 케이블로 노트북을 Type C-Port 1 에 연결합니다.
  2. BKFIL에서 COM 포트를 선택하고 하드웨어에 연결합니다.
  3. 필요한 .bin 파일 경로를 선택합니다(예: all-app.bin).
  4. Reset Switch Button(R1 오른쪽)을 누른 상태에서 Burn 을 클릭합니다.
