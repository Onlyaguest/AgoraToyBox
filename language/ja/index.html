はじめに

手順 1：電源オン

  • バッテリーケーブルをコネクタに接続します
  • 振動が止まるまで “Middle Switch” を長押しします
  • 離すと赤い LED が点滅し、音声で “the network connection is failed, please check your network” と案内されます

手順 2：ネットワーク設定モード

  • “Left Switch” を 3 秒以上長押しします
  • 音声で “Please use bluetooth for network provisioning” と案内されます

手順 3：ConvoAI App をインストールしてログイン

  1. 右の QR コードから ConvoAI App をダウンロードしてインストールします
  2. ConvoAI App を起動します
  3. “Call AI Engine” をタップしてログイン画面へ進みます
  4. 権限の許可を行い、ログインを完了します

手順 4：ネットワーク設定

  1. 左上のメニューボタンをタップします
  2. “Conversational AI Devices” の “+” をタップします
  3. 右上の “+” をタップして新しいデバイスを追加します
  4. “Next” をタップして次へ進みます
  5. 対象デバイスが表示されたら、デバイス名をタップします
  6. Wi‑Fi 名を確認します
  7. Wi‑Fi パスワードを入力し “Next” をタップします
  8. 3〜5 秒待ち “Device Added” が表示されれば完了です

手順 5：会話を開始

  • ウェイクワード：“Hi, AGORA”（3〜5 秒待つと目の画面が点灯し、赤い LED の点滅が止まります）
  • 次のコマンドも試せます：
    • “Introduce AGORA company”
    • “Who is Bill Gates”
    • “What's 15% off a $328 dress?”

手順 6：電源オフ／スリープ

  • 3 分間操作がないと自動でスリープ（音声：“AI Agent Disconnected”）
  • スリープ：赤い LED が消灯し振動が止まるまで “Middle Switch” を長押しします
  • 完全に電源を切る：バッテリーコネクタを外します

FAQ

電源操作

  • 電源オン：Middle Switch（S2）を 3 秒以上長押し
  • 電源オフ：起動中に Middle Switch（S2）を 3 秒以上長押し

ネットワーク設定

  • 設定モード：起動中に Left Switch（S1）を 3 秒以上長押し
  • デバイスはネットワーク設定待機状態になります

音量

  • 音量アップ：Left Switch（S1）を 1 回押す
  • 音量ダウン：Right Switch（S3）を 1 回押す

ロール切り替え

  • 1：アプリからロールを切り替えます
  • 2：本体右側の Reset Switch（K1）でも切り替え可能です
  • 注意：切り替え後、再度ウェイクして完了させてください

充電

  • どの Type‑C ポートでも充電できます
  • 注：バッテリーなしでも Type‑C ケーブル直結で電源供給・使用できます

ホットスポットのみで設定

  • 事前にホットスポットを設定しておくとネットワーク設定を省略できます：
  • 名前：AGORA_AI_KIT
  • パスワード：1234567890

LED ステータス

  • 赤/緑が交互に点滅：ネットワーク設定待ち
  • 赤が点滅：ネットワーク接続待ち
  • 緑が点滅：ネットワーク接続済み／AI Agent 未接続／ウェイク待ち

ウェイクアップ

  • ウェイクワード：“Hi, AGORA”

ウェイクのタイムアウト

  • AI Agent Disconnected：3 分
