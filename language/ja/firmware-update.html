ファームウェア書き込み（Burn Code）

Armino と BKFIL を使った書き込み手順をまとめました。

ホームへ

クイックチェックリスト

  • USB ケーブルで PC を Type C-Port 1 に接続します。
  • CH340 シリアルツールボード の使用を推奨します（baud rate 1500000）。
  • BKFIL を準備: Windows（BKFIL.exe）/ macOS（BKFIL）。
  • all-app.bin を用意（セキュリティプロジェクト初回は bootloader.bin も）。

概要

Armino は Windows/macOS でのファームウェア書き込みに対応しています。このページでは、必要なファイルと操作を実行しやすい形に整理しています。

ビルド生成物（.bin）

アプリをビルドすると、build/app/bk7258/ に all-app.bin が生成されます。このファイルを書き込みできます。

セキュリティプロジェクトの初回書き込み

まず bootloader.bin を書き込み、その後 all-app.bin を書き込みます。

シリアル（UART）で書き込み

備考

  • Type C-Port 1 経由の書き込みに対応しています。
  • ダウンロードには CH340 シリアルツールボード を推奨します。
  • Windows では現在 UART 書き込み をサポートしています。

書き込みツール（BKFIL）

ツールの入手:

  • Windows: BEKEN_BKFIL_V3.0.1.4_314_20240924.zip
  • macOS: BKFIL_macos_v4.0.1_25091001.zip

手順

  1. ケーブルで PC を Type C-Port 1 に接続します。
  2. BKFIL で正しい COM ポート を選択し、ハードウェアに接続します。
  3. 書き込む .bin ファイルを選択します（例: all-app.bin）。
  4. R1 右側の Reset Switch Button を押したまま、Burn をクリックします。
